# ⚛️ React: Fundamentos de Desenvolvimento Web

`STATUS` **EM DESENVOLVIMENTO**

> Repositório dedicado à disciplina de Desenvolvimento de Sistemas Web, com foco em fundamentos de front-end: estruturação de páginas, estilização moderna e introdução a bibliotecas JavaScript, desenvolvidos durante a graduação de ADS.

---

## 🚀 Tecnologias e Ferramentas

- **Linguagens:** HTML5, CSS3, JavaScript
- **Biblioteca:** React
- **Estilização:** TailwindCSS
- **Ambiente:** VS Code

## 📘 Conteúdos Praticados

- **Estruturação de páginas:** organização semântica de HTML e componentes.
- **Estilização utilitária:** aplicação de classes TailwindCSS para layout responsivo.
- **Lógica de interface:** manipulação de DOM e eventos em JavaScript.
- **Desafios práticos:** exercícios de fixação aplicados em sala de aula.

## 📁 Estrutura do Repositório

- `index.html` — página inicial/base do projeto.
- `tailwindCSS.html` — exercícios de estilização com TailwindCSS.
- `desafio_aulas_3e4.html` — desafio prático das aulas 3 e 4.
