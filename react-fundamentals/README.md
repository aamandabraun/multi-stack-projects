# ⚛️ React Fundamentals: Desenvolvimento Web Full-Stack

> Repositório dedicado à prática de desenvolvimento web, unindo interfaces em HTML/Tailwind CSS a APIs REST seguras com Node.js, Express e SQLite, desenvolvidas durante a graduação de ADS.

---

## 🚀 Tecnologias e Ferramentas

- **Front-end:** HTML5, Tailwind CSS
- **Back-end:** Node.js, TypeScript, Express
- **Banco de dados:** SQLite (`better-sqlite3`)
- **Ambiente:** VS Code + REST Client
- **Paradigma:** Orientado a rotas (API REST)

## 📘 Conteúdos Praticados

- **API REST:** implementação completa de rotas GET, POST, PUT, PATCH e DELETE.
- **Segurança:** Prepared Statements contra SQL Injection, allowlists e type guards para validação de entrada.
- **Consistência de dados:** transações (`db.transaction`) para atualizações parciais atômicas.
- **Tratamento de erros:** diferenciação entre erros de validação (400) e erros internos (500), sem vazar detalhes do banco.
- **Persistência de dados:** modelagem e consultas em SQLite.
- **Estilização de interfaces:** construção de telas responsivas com Tailwind CSS.

## 🎯 Objetivo

Aplicar os fundamentos de desenvolvimento web, partindo da construção de interfaces simples até a implementação de APIs REST robustas e seguras, com validação de dados, prevenção de SQL Injection e tratamento adequado de erros.
