## ⭐ Destaque

**Sistema de Atendimentos Técnicos** (dentro de `c-logic-projects/atendimento-inteligente`) — projeto completo em C que combina cinco estruturas de dados clássicas (fila dinâmica, lista encadeada, árvore BST, tabela hash e ordenação) em um único sistema funcional, com persistência em CSV. [Ver detalhes →](./c-logic-projects#-projeto-em-destaque-sistema-de-atendimentos-técnicos)

<br>

## 🚀 Sobre este repositório

Este repositório unifica quatro repositórios que antes existiam separadamente, preservando o histórico completo de commits de cada um (via `git subtree`). A organização por pastas facilita a navegação por stack, sem perder o contexto de quando e como cada projeto foi desenvolvido.

<br>

## 🧭 Como navegar

Cada subpasta funciona como um projeto independente, com seu próprio README explicando:
- Tecnologias e ferramentas utilizadas
- Conceitos/conteúdos praticados
- Estrutura interna de pastas e arquivos
