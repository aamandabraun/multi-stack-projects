# 📱 Flutter: Aplicações Mobile

`STATUS` **EM DESENVOLVIMENTO**

> Repositório dedicado ao desenvolvimento de aplicações mobile com Flutter, incluindo apps completos e exercícios de fixação, desenvolvidos durante a graduação de ADS.

---

## 🚀 Tecnologias e Ferramentas

- **Linguagem:** Dart
- **Framework:** Flutter
- **Ambiente:** VS Code / Android Studio
- **Paradigma:** Orientado a Widgets

## 📘 Conteúdos Praticados

- **Widgets e layout:** construção de interfaces responsivas com widgets nativos do Flutter.
- **Navegação:** fluxo entre telas (rotas) dentro do app.
- **Gerenciamento de estado:** manipulação de dados e reatividade da interface.
- **Estruturação de projetos mobile:** organização de código seguindo boas práticas Flutter.

## 📁 Estrutura do Repositório

- **`cardapio_digital/`** — aplicativo de cardápio digital, com listagem e detalhamento de itens.
- **`flutter_application_1/`** — projeto base/exercícios de fixação dos fundamentos do Flutter.

## 🎯 Objetivo

Aplicar os conceitos de desenvolvimento mobile multiplataforma, desde a estruturação básica de widgets até a construção de um aplicativo funcional completo.
